# AI Resume Screening Dashboard

An AI-powered Resume Screening Dashboard built using Python and Streamlit.

## Features

- Upload Job Description (.txt)
- Upload Multiple Resume PDFs
- Resume Ranking
- AI-based Similarity Score
- Search & Filter Candidates
- Recommendation Distribution
- Interactive Dashboard
- Excel & CSV Export

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- PyMuPDF
- Scikit-learn

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
